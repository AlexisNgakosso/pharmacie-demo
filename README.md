# Pharmacie Démo (version de test)

Site click & collect de parapharmacie avec une **pharmacie fictive**, publié uniquement pour tester le site depuis un navigateur (iPad, téléphone).
Aucune commande n'est réelle : les données restent dans le navigateur de chaque visiteur.

Ouvrir `index.html`, puis « Site client », « Administration » ou « Espace client ».
