Banc d'essai Pharmacie Démo

Le site complet, avec une pharmacie inventée, pour le tester dans Safari. Les commandes passées ici restent sur cet appareil : elles apparaissent dans l'administration ouverte dans ce même navigateur.

Dans chaque page, le petit menu « TEST » en bas à gauche permet de passer du site à l'administration, et de tout remettre à zéro.

Parcours conseillé (10 minutes)

  1. Site client : ajoutez deux produits au panier, saisissez le code BIENVENUE, puis commandez avec votre nom, une adresse email et un téléphone.
  2. Notez le numéro de commande et le code de retrait affichés dans la fenêtre de confirmation.
  3. Administration, page Commandes : votre commande apparaît « En préparation ». Cliquez sur Prête.
  4. Page Validation Scan : saisissez le code de retrait. La commande passe à « Retirée ». Ressaisissez-le : le site refuse un second retrait.
  5. Bouton Guide en haut de l'administration : lancez la visite guidée.
  6. Pour la fidélité : passez 5 commandes avec le même nom et le même email. À la 5e, un code de réduction s'affiche.

À savoir

  • Les emails sont coupés : les identifiants EmailJS ne sont pas dans cette version publique. Pour tester un vrai envoi : Administration, Paramètres, carte « Emails automatiques », saisissez le Service ID, le Template ID et la clé publique, activez l'interrupteur, puis Sauvegarder. Ils restent enregistrés seulement dans ce navigateur.
  • Noms, adresse et numéros sont inventés. La vraie version garde les informations de la pharmacie.
  • Cette page est publique mais non référencée par les moteurs de recherche. N'y saisissez pas de vraies données de clients.
